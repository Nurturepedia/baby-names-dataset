# Baby Names Dataset

A structured and growing collection of baby names categorized by origin, religion, country, zodiac sign, and other naming attributes.

This repository is maintained by Nurturepedia and is intended for developers, researchers, educators, data enthusiasts, and parents looking for organized baby name data in machine-readable formats.

---

## About This Dataset

The goal of this project is to make baby name information easier to explore, analyze, and build with.

The dataset is organized into multiple categories including:

- Origin-Based Names
- Religion-Based Names
- Country-Based Names
- Zodiac-Based Names

All data is maintained in a structured format to support research projects, educational applications, data analysis, and naming tools.
